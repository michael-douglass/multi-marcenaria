# Pontua — interface predefinida pelo master (requisitos)

1. A página Pontua não deve carregar em loop nem ficar presa em "Carregando perfil...".
2. O banner principal (`#pontua`) não pode exibir a marca da empresa (logo no globo nem nome nos textos) na interface padrão.
3. No console master (`/master/modelos`), cada empresa-modelo escolhe a interface da Pontua, com pré-visualização.
4. A escolha acompanha o pacote Pontua: vale para quem o receber; empresa com interface própria não é sobrescrita.

Interfaces: `sem_marca` (padrão) e `classica` (logo no globo e nome nos textos).
